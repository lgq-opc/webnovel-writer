## 发版范围

本次发布覆盖上个正式 tag `v8.0.0` 之后的 `v8.0.0..v8.1.0`（`v8-author` 分支）。来源：2026-09-04 全项目复审产出的「v8 功能缺口三轮复盘」——40 项缺口归并为 4 个修复阶段，同日全部完成并经 fantasy01 真仓冒烟。给作者的一句话：写章前 AI 看到的资料更厚更准，定稿闸门更严，书仓哪里有病 doctor 能查出来，面板上看得到每条伏笔的账。

## 给作者看的变化

- **写前上下文包 7→10 section**：新增 文风宪法、主角卡、视角纪律 等。在书仓 `book.yaml` 写一行 `主角: <正名>` 即生效：决策卡视角 ≠ 主角时自动注入单章视角纪律（视角人物五感唯一镜头、他人情绪只外显）；`定稿/设定/名册/<正名>.md` 存在时主角卡带全文。
- **settle 三道门禁 + 后置落账**：审查未通过 / 文笔 flag / 素材引用无效 → 拒绝定稿（`--bypass` 可显式越过并留账）；定稿成功后自动落 素材轨迹、文风指纹、追读力 三张表，写完即沉淀。
- **章纲批量一致性闸**：标题必须对上详细大纲、承诺必须已在账本、时间锚不得批内倒流，违者整批拒绝。
- **六项数据不变量体检**：journal 未分类积压 / 素材轨迹引用 / 力量锚点战例与境界链 / 条目状态机与 retcon 双记录 / 合同重建对账 / stale 超一卷未消费，`webnovel.py invariants` 一键跑。
- **doctor 治理体检**：纯 v7 书仓能解析项目根，12 组既有检查 + 8 组治理检查全部跑到真书仓（此前 v7 书上整体跳过）。
- **面板承诺账本视图**：治理面板第七段——各状态计数 + 逾期列表，只读。
- **复合题材播种 + 浮动名扫描**：`都市+仙侠+科幻` 复合题材按并集播种素材；`name-check --scan` 扫近章未入册高频专名，提醒入册。
- **书仓大纲去重**：迁移器不再剥「-详细大纲」后缀，同卷不再存两份逐章大纲。
