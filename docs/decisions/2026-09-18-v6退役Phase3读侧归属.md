## 决策

不重建 v6 投影体系。v7 读面 = 六域文件 + `v7-write pack` + MCP 查询。六条：

1. **dashboard**：纯 v7 明示不支持；存量 v6 仓维持只读。不接 `.cache`，不另建 v7 读侧。
2. **RAG**：正式下线。`memory/` 随 context 链冻结。
3. **`knowledge`**：v7 只答名册级，定为正式行为。设定全文走 `setting_read` / 六域文件。
4. **`extract-context` / `context_manager` 链**：现在冻结，目标退役，本轮不删；技能改指 `pack` 后再删。
5. **doctor 的 v6 合同检查 + `contract_migrations`**：保留。
6. **Phase 2 剩余**：批准「冻结而非删除」，Phase 2 收口。

## 理由

接 `.cache` 已于 2026-09-12 证伪（只有写链缓存表）。Phase 2 能安全删的簇已删完，剩余 CLI 仍被在役技能引用。另建读侧与当前 CLI/文件/MCP 工作方式不对等。
