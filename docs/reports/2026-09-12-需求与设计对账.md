### D-1 「六域」的第 6 个域是**文风**还是**演化**？——三处口径不一

| 出处 | 列举 | 性质 |
|---|---|---|
| 代码 `domain_contract.py:3` | 大纲 / 正文(定稿) / 设定 / 素材 / 作者 / **文风**（+演化事件域） | 【实测】实现口径 |
| 设计 `04-architecture.md:31` | 大纲域 / 正文域(定稿) / 设定域 / 素材域 / 作者域 / **演化域**（**无文风域**） | 【实测】架构图 |
| 设计 `05-book-directory-structure.md:6` | 标题写「**六域**总图」，图内实际**画了 7 个**：大纲域 / 素材域 / 设定域 / 正文域(定稿) / **文风域** / 作者域 / **演化域** | 【实测】自相矛盾 |

代码侧 `REQUIRED_DIRS` 含 `文风`、**不含任何演化目录** → 实现把文风当必备域、演化当附带。

**为什么不是笔误级**：它决定 doctor 的六域契约检查（`doctor.py:1146`）到底该查哪几个目录，以及新增书仓 `book-init` 该建哪套骨架。

**选项与裁决**：

- ✅ **A（已采纳，2026-09-12 Human 裁决）**：以代码为准 —— 第 6 域 = **文风**，演化是**附带事件域**。已执行：回改 `04:31`、`05:6` 标题与口径说明。
- **B**（未采纳）：以设计为准（第 6 域 = 演化）→ 需改代码契约（`REQUIRED_DIRS` 去文风、加演化）。
- **C**（未采纳）：承认实际七域，统一改称「七域」。

**裁决依据（决定性判据）**：**`演化/` 的三个使用点全部对目录缺失免疫**【实测】——

```
freeze_manager.py:108-109   evolution_dir.mkdir(parents=True, exist_ok=True)    ← 按需建
setting_forge.py:219-220    signals.parent.mkdir(parents=True, exist_ok=True)   ← 按需建
invariant_check.py:309-311  if not directory.is_dir(): return set()             ← 缺失降级为空集
```

故若把「演化」定为必备域，`book-init` 会建一个空目录、doctor 会在**每本新书**上报一条假 warning（新书什么都没发生过时 `演化/` 本就该为空）；而「文风」缺失是**真缺口**（无宪法/指纹/金句库 → 文风漂移无锚），warning 有意义。**代码侧的选择在工程上更稳**，故不采 B。

**两域的实际职责**（供后人查，【实测】）：

| 域 | 内容 | 承担 | 是否必备 |
|---|---|---|---|
| **文风域** | `宪法.md`（文风契约）· `金句库.md`（作者标记高分片段，素材自喂入口）· `指纹.yaml`（量化文风指纹：句长/口头禅/标点节奏，脚本可算） | 质量审阅 F-04「文风记忆在饱和时最先被牺牲」→ R5 提为 PROTECTED（`context_budget.py:57-60`）；T17/W6 `style_anchor` 接线（`729a505`） | ✅ 在 `REQUIRED_DIRS` |
| **演化域** | `run-ledger.jsonl`（settle/vol/ch/retcon/fix 事件链）· `signals.jsonl`（工坊采纳率 → 品味进化）· `freeze-v{NN}.json`（T10 冻结）· `retcon-v{NN}-{ts}.json`（retcon 事务） | 卷收尾冻结、retcon 三选项裁决、Inv-4「条目作废须同卷 journal+演化 retcon 双记录」（`invariant_check.py:368`） | ❌ 按需生成 |
